# AYESMAJ Studio repository instructions

## Image generation

- For every generated or edited image in this repository, use the official OpenAI Image API with the model ID `gpt-image-2`.
- Do not use Codex's built-in ImageGen tool for this repository.
- Read credentials only from the `OPENAI_API_KEY` environment variable. Never paste, print, log, or commit an API key.
- Keep generated website assets inside the existing public asset folders and optimize them for web delivery.
